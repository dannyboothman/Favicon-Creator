Changelog

15th August 2026
  • Saving now reports when local storage is full and drops oldest history entries to make room.
  • Editor updates no longer reload every control from storage on each change, which was overwriting text as you typed.
  • Font Awesome menu can be closed with the dropdown button; click or drop images to upload.
  • Download HTML/ReadMe snippets now list the ICO sizes that are actually in the zip (16 and 32).
14th August 2026
  • Added Image as a Visual option (upload PNG, JPEG, or WebP) with scale, position, and opacity controls.
  • Added Image as a Background option with the same upload and transform controls.
  • Download now renders selected favicon sizes in parallel and shows a clear error if zip generation fails.
  • Montserrat and Font Awesome are bundled locally so extension pages no longer load UI fonts from CDNs.
13th August 2026
  • Favicon preview stays square; extra characters are clipped instead of stretching the icon.
  • Added a History page to browse previously downloaded favicons, reload them into the editor, or delete them.
  • Fixed border radius not scaling correctly when downloading larger favicon sizes.
  • Fixed border width not scaling correctly when downloading larger favicon sizes.
  • Rounded favicons now export with transparent corners instead of a white background.
  • Added ability to use a radial gradient background.
  • Radial gradients support shape (circle/ellipse) and position controls.
12th August 2026
  • Theme toggle now supports Light, Dark, and System (follows your OS preference).
  • Downloading favicons no longer resizes the on-screen preview or causes the popup to jump.
  • Download button now shows "Downloading" and is disabled while the zip is being generated.
  • Restored live preview of your favicon in the current browser tab.
10th November 2023
  • Added ability to add a linear gradient.
  • Removed "Active Tab" permission.
11th June 2022
  • Updated to Chrome Extension Manifest 3
  • Removed permissions that are no longer required.
  • Removed functionality to display the Favicon in the browser tab until a new solution is found.
  • Added warning about border scaling issue.
22nd Jan 2019
  • Text and background design elements are now split into two tabs to create more room.
10th Jan 2019
  • You can now change the border radius of your favicon. Slight scaling issues when downloading larger size favicons.
  • 128 x 128 and 256 x 256 image sizes are now de-selected by default.
09th Jan 2019

    1. Bold
    2. Italic
    3. Underline (only available for sizes 16, 32 & 64)
    4. Line-through
07th Jan 2019

  • You can now click outside the FontAwesome menu to close the menu.
04th Jan 2019
